The root is a private Next.js app with no separate npm packages — child directories under `src/` (`app_shell`, `business_features`, `dashboard_features`, `shared_features`, `ui_components`, `cross_cutting`) are sibling source trees consumed via the `@/*` path alias declared in `tsconfig.json`. The shell (`app_shell`) owns runtime wiring: it registers route groups for public pages, authenticated dashboard routes, and server-side API endpoints, then wraps them with providers from `shared_features` (auth provider, dashboard chrome). Feature modules import UI primitives from `ui_components` and runtime services (NextAuth v5, Firebase client/admin SDKs, theme provider, hooks) from `cross_cutting`; they never depend on each other. `components.json` centralizes shadcn/ui configuration (New York style, CSS variables, lucide icons) so every child generates components against the same design tokens, and `firestore.rules` is the single security boundary enforced at the database layer across all features. All dependencies are pinned centrally in the root `package.json` and shared by every child module.

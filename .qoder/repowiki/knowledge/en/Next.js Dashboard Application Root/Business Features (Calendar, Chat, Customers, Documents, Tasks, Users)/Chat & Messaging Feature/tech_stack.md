React Server Components client boundary (`"use client"`) + Zustand for in-process state; date formatting via `date-fns`; icons from `lucide-react`; UI primitives from the project's shadcn/ui registry (`Avatar`, `Badge`, `DropdownMenu`, `ScrollArea`, etc.). Data is loaded through a shared `getFirestoreCollection` helper so the same API can later be wired to Firebase without changing the store surface.

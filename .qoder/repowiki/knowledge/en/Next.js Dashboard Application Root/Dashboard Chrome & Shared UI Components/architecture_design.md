Flat collection of `src/components/*.tsx` files with no internal sub-packages; each file is a self-contained client component (`"use client"`) that composes primitives from `@/components/ui/*` (shadcn Radix wrappers) and `lucide-react` icons. Two layers exist:
- Shell layout: `app-sidebar.tsx` owns navigation data and groups, delegating to `nav-main.tsx`, `nav-secondary.tsx`, `nav-user.tsx`; `site-header.tsx` wires in `command-search.tsx` and `mode-toggle.tsx`; `site-footer.tsx` is a static footer.
- Feature providers: `auth-provider.tsx` wraps children in NextAuth's `SessionProvider`; `theme-provider.tsx` drives `ThemeProviderContext` from `@/contexts/theme-context`, persisting the chosen theme to localStorage under `vite-ui-theme` and toggling `light`/`dark` classes on `documentElement`.
Heavy or SSR-incompatible pieces (`ThemeCustomizer`, `ColorPicker`) are lazy-loaded through `dynamic-imports.ts` via `next/dynamic` with `ssr: false` and a pulse placeholder. Cross-cutting concerns live outside this scope — auth state comes from `next-auth/react`, permissions from `@/lib/auth/permissions`, Firebase sign-out from `@/lib/firebase/auth`, and theme hooks from `@/hooks/use-theme` / `@/hooks/use-circular-transition`. Visual-only helpers (`logo.tsx`, `image-3d.tsx`, `dot-pattern.tsx`, `pricing-plans.tsx`) are pure presentational components with no side effects.

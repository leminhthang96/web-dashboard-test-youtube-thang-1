Three sibling sub-packages with one-way dependency direction: `ui/` is the leaf primitive layer (each file is a self-contained Radix-based component exported as named React components, often paired with a `cva`-driven variants object such as `buttonVariants`, `badgeVariants`, `fieldVariants`); `layouts/base-layout.tsx` composes `AppSidebar`, `SiteHeader`, `SiteFooter` and wraps children in `SidebarProvider`/`SidebarInset`, exposing a single `BaseLayout` contract; `theme-customizer/` is a client-only (`"use client"`) sheet-driven panel (`index.tsx` → `ThemeCustomizer` + `ThemeCustomizerTrigger`) split into `ThemeTab`, `LayoutTab`, and `ImportModal`, driven by `useThemeManager` and `useSidebarConfig` hooks and applying changes via CSS custom properties rather than class toggles. All three layers depend on shared utilities (`@/lib/utils` `cn`, `@/hooks/*`, `@/contexts/sidebar-context`, `@/config/theme-data`, `@/types/theme-customizer`) but never on each other except `base-layout` importing `ThemeCustomizer`. The `ui/` directory mirrors the shadcn CLI scaffold — one file per primitive, no barrel index — so consumers import directly from `@/components/ui/<name>`.

Firebase client requires all `NEXT_PUBLIC_FIREBASE_*` environment variables to be present at import time — missing values throw immediately via `validateFirebaseEnv()`. Firebase Admin SDK accepts either three split env vars (`FIREBASE_ADMIN_PROJECT_ID`, `FIREBASE_ADMIN_CLIENT_EMAIL`, `FIREBASE_ADMIN_PRIVATE_KEY` with literal `\n` newlines) or a full `FIREBASE_SERVICE_ACCOUNT_KEY` JSON blob, falling back to Application Default Credentials on Google Cloud.

Organized as Next.js route groups under `src/app/(auth)/`, which share the top-level `layout.tsx` that sets the page title/description and a full-height background container. Each feature is a self-contained folder with a thin `page.tsx` shell delegating to a sibling `components/<feature>-form.tsx` client component — e.g. `sign-in/page.tsx` → `components/login-form.tsx`. The `errors/` sub-group mirrors this pattern for five static error routes (`not-found`, `unauthorized`, `forbidden`, `internal-server-error`, `under-maintenance`). Forms are pure client components (`"use client"`) built on react-hook-form + zod schemas, calling Firebase auth helpers from `@/lib/firebase/auth` and then signing in via NextAuth's `signIn("credentials")` before redirecting to `/dashboard`. UI primitives come from the shared `@/components/ui/*` shadcn kit; there is no server-side data fetching or API route inside this module.
